# Repository map

This repository holds several independent projects. Keep changes inside the one you're working on.

- `Sosies/` — **SOSIES**, an Unreal Engine 5.8 psychological horror game. Read `Sosies/CLAUDE.md` before doing any SOSIES work.
- `examquest/` — **ExamQuest**, a React + Vite web app.
- `app.js` — **Athletic Day**, a vanilla JavaScript PWA.
